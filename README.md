專案名稱：智慧隨機生成數獨與非阻塞計時挑戰賽
開發語言：C++ 
主要技術：非阻塞鍵盤偵測（Non-blocking I/O）、遞迴回溯演算法（Recursive Backtracking）、ANSI 游標防閃爍控制、高精度單調時鐘（steady_clock）。
遊戲規則
本遊戲在傳統數獨規則的基礎上，引入了現代遊戲的動態懲罰與難度約束機制：
1.	基本數獨規則：
o	在 9x9 的棋盤上，每一橫列（Row）、每一直行（Column）以及每一個 3x3 的九宮格（Box）內，數字 1-9必須恰好出現一次，不可重複。
2.	容錯機會上限：
o	每局遊戲玩家最多擁有 3 次 犯錯機會。
o	當玩家填入錯誤數字時，正確數字將無法填入，且錯誤次數加 1。當累計達到 3次錯誤時，遊戲立即宣告失敗。
3.	時間與挑戰限制：
o	一般模式（簡單、普通、困難）：無時間限制，畫面會正向累計時間，供玩家在無壓力的情況下進行遊玩。
o	極限模式：高強度的生死挑戰！玩家必須在 5 分鐘（300 秒）內通關，時間歸零即判定失敗。
4.	提示系統約束：
o	在簡單、普通、困難模式下，玩家擁有 3 次 智慧提示機會。
o	在極限模式下，提示功能完全禁用。
程式介紹 (架構與技術特點)
本專案擺脫了傳統主控台遊戲「輸入會卡住時間」與「高頻刷新造成畫面閃爍」的硬體限制，具備以下四大軟體工程特點：
1. 模組化架構設計 (Modular Architecture)
專案嚴格切分為三個獨立的邏輯層級，大幅提升代碼的可讀性與可維護性：
•	main.cpp (程式進入點)：只負責控制器（Game）的初始化與啟動。
•	Sudoku.h / Sudoku.cpp (Model 邏輯資料層)：
o	負責儲存玩家當前棋盤（grid）與正確解答（solution）。
o	實現基本的行、列、九宮格規則比對（isSafe）。
o	內建核心的隨機謎題生成演算法（generatePuzzle）。
•	Game.h / Game.cpp (Controller / View 控制與視圖層)：
o	實作以 50 FPS（每 20 毫秒刷新一次）運行的畫面重繪主迴圈。
o	監聽使用者的非阻塞輸入，計算高精度時間流逝，並繪製對齊美觀的 ASCII 棋盤。
2. 50 FPS 非阻塞輸入與計時系統 (Non-blocking I/O)
傳統 C++ 使用 std::cin 讀取輸入時會造成執行緒「阻塞」，導致時間倒數中斷。本專案透過 <conio.h> 的 _kbhit() 與 _getch() 進行底層無延遲監聽，配合 C++ 的 std::chrono::steady_clock，實現了「時間持續精準流逝，同時玩家能即時打字作答」的視窗級流暢操作。
3. 對角線打底與遞迴回溯演算法 (Backtracking Generator)
•	對角線打底 (fillDiagonal)：利用對角線的三個 3x3 宮格在橫列與直行上完全不重疊的幾何特性，隨機塞滿基礎數字。此步驟為盤面注入了隨機基因，確保每次開局都是全新題目。
•	遞迴回溯求解 (fillRemaining)：這是一個強大的自動求解引擎。從對角線往外一格一格嘗試填入 1~9，遇到死胡同就自動擦除重來（回溯），在幾毫秒內就能推導出 100% 有解的完整解答，並將其保存為標準答案紙。
•	智慧隨機挖空 (removeKDigits)：根據難度（簡單挖 30 格、普通 42 格、困難/極限 54 格），利用隨機數在盤面上挑選格數擦除。
4. ANSI 游標防閃爍技術 (Anti-Flicker Engineering)
主控台的高頻率原地重繪（每秒 50 次）通常會帶來極嚴重的游標狂閃問題。我們透過 ANSI 轉義序列實作了 「游標隱形控制」：
•	每次重繪畫面與棋盤前，先呼叫 \033[?25l 隱藏游標。
•	當畫面所有內容、計時器、棋盤全部印製完畢，且游標定位在玩家輸入欄位後，再呼叫 \033[?25h 顯示游標。
•	搭配行清除命令 \033[K，徹底消除了字元變短時產生的殘影，達到極致穩定的視覺效果。
玩法與操作說明
1. 啟動與選擇難度
執行程式後，主控台會顯示難度選單，請輸入數字 1 到 4 進行選擇：
•	[1] 簡單：挖空 30 格，容錯 3 次，提示 3 次，無時間限制。
•	[2] 普通：挖空 42 格，容錯 3 次，提示 3 次，無時間限制。
•	[3] 困難：挖空 54 格，容錯 3 次，提示 3 次，無時間限制。
•	[4] 極限：挖空 54 格，容錯 3 次，不提供提示功能，且限時 5 分鐘。
2. 輸入作答
在最下方的作答欄位中，依照格式輸入 [列座標] [行座標] [填入數字]（三個數字以半形空白隔開），並按下 Enter 送出。
•	例如：要在第 3 列、第 5 行填入數字 9，請輸入：3 5 9。
•	如果位置已被填寫或超出 1~9 範圍，系統會發出提示警告。
•	如果填入的數字與標準解答不符，該格會保持留白，錯誤機會減 1。
3. 使用智慧提示
在簡單、普通、困難難度下，若遇到瓶頸，可以在作答欄位中輸入 0 0 0 並按下 Enter：
•	系統會即時重新掃描盤面上的所有空格，隨機挑選一格自動填上正確答案，並扣除提示機會。
•	在極限模式下強行輸入 0 0 0，防呆機制會予以攔截。
程式如何安裝與執行
